# Petit CRM en Go

Un petit **CRM (Customer Relationship Management)** développé en **Go**.

## Membres du groupe

- **Lucas TREILLE**  
- **Asâad MEHIDI**

## Prérequis

- **Go** (1.21+ recommandé)

## Installation / Clonage

  ```bash
  # Cloner le dépôt
  git clone https://github.com/lucastreille/crm-go.git
  cd crm-go
  
  # (Optionnel) Se placer sur la branche Main
  git checkout Main
  ````

## Lancement du projet

1. Se placer sur la branche **Main** (ou dans le dossier racine du projet).  
2. Exécuter la commande suivante :

   ```bash
   go run .
   
L’application démarre et expose les endpoints du CRM (voir la section “Endpoints” si disponible).
